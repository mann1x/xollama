# OpenWolf

- Read `.wolf/anatomy.md` before opening a project file; if a file is missing
  from it, add an entry after you touch it.
- Check the Do-Not-Repeat list in `.wolf/cerebrum.md` before generating code.
  Record corrections, conventions and decisions there as soon as you learn them.
- Read `.wolf/buglog.json` before fixing an error, and append afterwards with
  `error_message`, `root_cause`, `fix`, `tags`.
- Append one line per significant action to `.wolf/memory.md`.
- Editing the same file more than twice in a session means a bug — log it.
