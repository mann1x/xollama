# llama/runtime-pin-linux-arm64.txt
#
# The Linux arm64 payload of the container image, the counterpart of
# llama/runtime-pin-linux.txt (which documents every directive) and read by
# the same script: ARCH=arm64 scripts/docker-assemble.sh.
#
# The CPU runtime is the fork's, built in the same run as the amd64 one from
# the same commit (fork run 37176344596: a native arm64 runner, AlmaLinux 8,
# upstream's cpu preset; glibc 2.27, 64K-aligned segments, CPU variants
# armv8.0 to armv9.2 chosen at load). It moves with
# llama/runtime-pin-linux.txt: one fork release, one commit, both
# architectures.
#
# The gpu rows are upstream's arm64 tarballs, as its own arm64 image carries
# them: CUDA 12 and 13 for arm servers, and the two JetPack payloads. A
# Raspberry Pi uses none of them and runs on the CPU.
